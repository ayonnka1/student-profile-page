Практическая работа №1

Запуск и тестирование локального сервера Apache

● Статус: Сервер активен

💻 Информация о разработчике

Имя студента: Шайдуллаева Амина

Операционная система: Windows 11

Серверное ПО: Apache (из пакета XAMPP)

Рабочий каталог: C:\xampp\htdocs\labsite

📌 Поставленная задача

Развернуть локальное окружение Apache, разместить веб-страницу в рабочем каталоге и организовать к ней доступ по сети Wi-Fi через IPv4.

📋 Порядок выполнения

  1. Старт службы: Запущен модуль Apache через панель управления XAMPP.
  2. Публикация: В директории htdocs создана папка labsite с файлом index.html.
  3. Определение IP: С помощью команды ipconfig в консоли найден сетевой IPv4-адрес.
  4. Проверка доступа: Выполнено успешное подключение к сайту с внешних устройств в локальной сети.

🔗 Локальный URL-адрес

Для просмотра сайта с других устройств в текущей Wi-Fi сети используйте адрес:

http://[ВАШ_IP_АДРЕС]/labsite
